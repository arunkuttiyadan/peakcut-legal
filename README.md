# PeakCut legal site

Static, GitHub Pages-ready site for PeakCut's Terms of Service and Privacy Policy.

## Pages

- `terms.html` — Terms of Service
- `privacy.html` — Privacy Policy
- `index.html` — landing page linking both policies

The pages use the owner name **Shambunni** and contact **ziztrogaming@gmail.com**.

## Publish with GitHub Pages

1. Create a separate public GitHub repository named `peakcut-legal` under the intended GitHub account.
2. Add the contents of this folder to the repository's root and push to its default branch.
3. In the repository, open **Settings → Pages** and choose **Deploy from a branch**, the default branch, and `/ (root)`; save.
4. After GitHub Pages finishes publishing, the site and policy links will be at `https://<account>.github.io/peakcut-legal/`, `/terms.html`, and `/privacy.html`.
5. Open each public URL to confirm it loads, then enter the Terms and Privacy URLs in TikTok for Developers.

If TikTok asks you to verify a domain, download the verification file from TikTok and add it to the repository root with its exact filename and contents. The token is specific to your app and cannot be prepared in advance.

## Before submitting

Review the policy wording against the actual app behavior, especially which account fields and video data PeakCut accesses, where it stores them, and for how long. Update the “Last updated” date when making material edits. These pages are a practical draft, not legal advice.
